\section{Trabajos Futuros}
Con base en el resultado del proyecto, se recomiendan las siguientes actualizaciones para ampliar las funcionalidades del sistema:
Incorporar el manejo de roles y permisos, actualmente la institución no distingue tipos de usuarios y solo se identifican por áreas, por lo que el sistema no tiene usuarios con roles o permisos especificos, cualquier empleado que ingrese a la plataforma mediante el enlace de autenticación puede realizar todas las acciones disponibles en el sistema, lo ideal sería que existieran usuarios con sus debidos permisos. 

Relacionado con lo anterior, el sistema tambien podría implementar un apartado de información de la sesión, donde se pueda consultar el historial de ese usuario y así ver todas las acciones de una forma más fácil.

Otra funcionalidad que puede hacer más completo el sistema, es agregar la búsqueda por contenido, buscar por palabras clave dentro del contenido de los documentos, lo cual facilitaría encontrar documentos específicos sin necesidad de recordar el nombre exacto.

Finalmente, se propone la implementación de un sistema de notificaciones por correo electrónico cuando se sube o elimina un documento importante para la institución, por ejemplo aquellos que son compartidos entre distintas áreas del PJETAM.
