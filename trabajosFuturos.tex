\section{Trabajos Futuros}

Hay algunas mejoras para el sistema, como el manejo de roles y permisos, actualmente el sistema no tiene usuarios con roles o permisos especificos, cualquier empleado que entre a la plataforma mediante el enlace de autenticación puede realizar todas las acciones disponibles en el sistema, y seria mejor que existieran usuarios con sus debidos permisos. Por el momento la institución no distingue tipos de usuarios y solo se identifican por áreas.
Al distinguir entre usuarios el sistema tambien podría implementar un apartado de información de la sesión donde se pueda consultar el historial de ese usuario, para ver todas las acciones de una forma más fácil.

Otra funcionalidad que puede hacer más completo el sistema, es agregar la búsqueda por contenido, buscar por palabras claves dentro del documento.

El sistema actual no maneja ningún tipo de notificaciones por lo que considero importante agregar notificaciones por correo electrónico cuando se sube o elimina un documento importante, o que sea de uso común entre las áreas.
